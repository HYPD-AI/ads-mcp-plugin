# What HYPD can do

HYPD analyzes the user's real advertising data, read-only: it never changes campaigns, budgets or ads.

**Platforms:** Google Ads · Meta (Facebook) Ads + Ad Library · Google Analytics (GA4) · Merchant Center · Microsoft Ads · LinkedIn Ads — plus keyword research, competitor/SERP/Shopping research, and landing-page checks.

**Ready-made workflows** (each has its own skill with the exact steps):

| Ask for | Skill |
|---|---|
| Google Ads audit · wasted spend · negative keywords | hypd-google-ads-audit |
| Meta Ads audit (ecom or lead-gen) | hypd-meta-ads-audit |
| Creative analysis, own or competitor | hypd-creative-analysis |
| Keyword research, new campaign or expansion | hypd-keyword-research |
| Monthly client report · GA4 attribution comparison | hypd-reporting-attribution |
| Merchant Center feed quality · landing-page audit | hypd-shopping-feed-and-pages |
| Browse the full analysis library (87+) | hypd-prompt-library |

In Claude Code, the same workflows are also available as slash commands under the `hypd-ai-ads` namespace (`/audit`, `/wasted-spend`, …).

Anything else: just ask in plain language — HYPD's server routes to the right internal skill automatically.
