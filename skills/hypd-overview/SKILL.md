# What HYPD can do

HYPD analyzes the user's real advertising data, read-only: it never changes campaigns, budgets or ads.

**Platforms:** Google Ads · Meta (Facebook) Ads + Ad Library · Google Analytics (GA4) · Merchant Center — plus keyword research, competitor/SERP/Shopping research, and landing-page checks.

**Slash commands** (namespace `hypd-ai-ads`):

| Command | What it does |
|---|---|
| `/audit` | full Google Ads account audit |
| `/wasted-spend` | find wasted spend, with the money behind each finding |
| `/negatives` | negative-keyword candidates from search terms |
| `/keywords` | keyword research, new campaign or expansion |
| `/feed-audit` | Merchant Center feed quality |
| `/meta-audit` | Meta Ads audit, ecom or lead-gen |
| `/creative` | creative analysis, own or competitor |
| `/attribution` | GA4 Data-Driven vs Last-Click comparison |
| `/landing-page` | technical landing-page audit |
| `/report` | client-ready monthly report |
| `/prompts` | browse the full prompt library (87+) |

Anything else: just ask in plain language — HYPD's server routes to the right internal skill automatically.
